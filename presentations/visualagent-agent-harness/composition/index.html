07 / 15
07 / Observation & Trajectory

每一步都先成为事实，再进入只追加、可脱敏的证据链。

Observation

ok、content、error；只描述当前工具实际发生了什么。

Safety Filter

secret、token、base URL → redacted；prompt → SHA-256。

Trajectory

run、step、final、evaluation 与 training lock。

08 / Evaluator

技术通过只是第一关；训练资格需要三层独立门禁。

GATE 01

Technical

文件、时长、分辨率、音轨、透明层。

GATE 02

Semantic / Visual

身份、手部、商品几何、因果与可读性。

GATE 03

Human Approval

明确 accept / reject、reviewer、note。
