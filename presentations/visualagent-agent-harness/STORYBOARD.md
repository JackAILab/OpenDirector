# VisualAgent Agent Harness

1. Harness 把模型调用变成可审计生产系统。
2. 一次性脚本无法回答成本、失败、重试和训练资格。
3. 八个边界构成唯一执行链路。
4. Task 是不可变生产合同。
5. Agent 只选择有界 action。
6. Runner 独占 loop、预算与停止条件。
7. Tool 与 Model 分开控制能力和 provider protocol。
8. Observation 与 Trajectory 把过程变成证据。
9. Evaluator 与 human review 共同决定训练锁。
10. Timeline 是直播生产唯一标准时钟。
11. 神经画面与可读 UI 必须分属不同 owner。
12. 直播 case 按 reference state → segment → layer → composite 执行。
13. Paid retry 是有预算、有 lineage 的新 run。
14. Asset Studio 是只读 projection，不是事实源。
15. 通过 flywheel，把一次 case 变成可复用数据系统。

分支页：`harness/` 目录到职责的仓库映射。
