# 项目构成与数据边界

## 源码

| 目录 | 内容 | 部署角色 |
|---|---|---|
| `gateway/` | 从配套 VisualStation 导出的账户、会话、积分、任务归属网关 | 必需；与工作室同源 |
| `harness/core/` | Task、Runner、状态与执行循环 | 必需 |
| `harness/agents/` | Director 规划、追问、工具策略 | 真实 Agent 功能需要文字模型 |
| `harness/models/` | Kling、文字模型、图片、语音等适配器 | 依服务配置启用 |
| `harness/tools/` | 受控生成、画布、编辑、合成、素材动作 | 必需 |
| `harness/studio/` | 项目、图片、视频输入、编辑、3D、管理 API | 必需 |
| `harness/library/`、`harness/learning/` | 广告参考索引、审核和学习资产流程 | 可选素材库 |
| `tools/agent_studio/` | 首页、登录、统一画布/故事板、编辑器、管理页 | 默认网页 |
| `tools/agent_studio/scene/` | Three.js 场景编辑器源码与固定 npm lock | Docker 构建时生成 bundle |
| `tools/asset_studio/` | 独立资产审阅站源码 | 可选独立工程，不由默认 Compose 启动 |
| `productions/`、`presentations/` | 案例工程与演示工程的可编辑源码 | 媒体由 ModelScope 恢复 |
| `configs/`、`data/` | 工具/模型/任务契约、小型配置与提示词 | 不含线上密钥 |
| `tests/` | Python 和浏览器回归 | 部分测试需要专用服务 |
| `deployment/local/` | Docker 构建、随机配置初始化、进程启动 | 本地部署入口 |
| `assets.lock.json` | 私有资产版本、大小、SHA-256 | 固定源码与资产对应关系 |

此发布是当前工作区的源码快照，包含尚未合入原仓库的素材库更新；不是旧仓库 Git 历史镜像。原先位于其他工程的必要网关代码现已随包包含。归档分支不恢复进入本包。

## 素材与本机状态

- **showcase**：生产/演示工程引用的图像、视频、音频、字体，恢复原相对路径。只包含当前实际存在的文件，不补造历史遗失素材。
- **library**：广告参考素材与一致性 SQLite 索引快照。保留来源与原作者信息；私有存放，不把第三方作品改成开源许可证。
- **不发布**：线上账户和积分数据库、用户私有创作项目、密码和 API keys、认证 cookie、模型 CLI 登录状态、供应商临时日志、缓存下载片段与依赖安装目录。
- **自行安装**：Python/npm 依赖、FFmpeg、Chromium；镜像负责安装。
- **自行配置**：真实 Director、Kling、可选 ASR/H3 服务及其访问权限。私有模型权重不在本资产集。

## 本地是否“一模一样”

本地使用同一工作室源码和网关，入口、画布、工具、账户/积分与本地持久化逻辑一致。线上账户、项目列表和余额会从空库开始；真实生成受你配置的模型型号、服务版本、授权、额度与网络影响，不保证复现相同随机生成画面。下载 showcase 不会自动把历史媒体导入新账户项目；需要在画布上传/引用。完整库属于独立入口，不会展示给普通创作用户。

## 备份与升级

在没有进行中任务时停止服务，备份 Docker `studio-data` 卷、`outputs/`、`assets/library/` 以及单独加密保管的凭证。不要仅备份源码就删除运行卷。升级使用匹配的 `assets.lock.json`；资产下载器拒绝覆盖不同内容，可先下载到新的目录后人工迁移。
