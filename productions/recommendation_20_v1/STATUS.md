## 界面与 API

- `tools/agent_studio/index.html` + `canvas.js/css` 为新工作室；已在无生成/规划任务的窗口部署，已统一为单一入口。原界面的临时部署回退副本仅在私有运行目录，不进入仓库。

- 图片用于导演视觉理解；视频限 30 MB / 60 秒 / 4K，抽取三帧供导演理解构图；不宣称已经分析音轨和完整运动。视频模型直接条件仍使用单独的商品参考图。
- 改变已连接输入使方案失效，需要重新规划、重新确认预算；只移动节点不改变方案内容。冲突保存保留草稿。
