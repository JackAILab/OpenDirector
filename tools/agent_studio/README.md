# Agent 导演工作室

当前运行入口是本机 30080 的 `/` 与 `/creative`。账户页为 `/account`，原有 Asset Studio 50442 继续承载历史作品审阅。

## 职责

- `harness/studio/api.py`：复用 VisualStation session、项目归属检查、版本检查和显式预算确认。
- `harness/studio/store.py`：私有项目 SQLite、单独追加的脱敏事件表。
- `harness/agents/creative_director.py`：带上下文的追问和分镜策略；只要求公开决策摘要。
- `harness/models/creative_director.py`：服务端配置的文字模型适配器；没有隐式模型切换。
- `harness/core/creative_runner.py`：串行生成、任务恢复、停止边界、合成和质检状态。
- `harness/tools/creative_video.py`：经原网关提交，继承配额、所有权和幂等性。
- `harness/tools/creative_render.py`：同一时间轴编译 HyperFrames，保留真实源音轨。
- `tools/agent_studio/index.html`：导演对话、预览、多轨时间轴、镜头编辑与制作记录。

## 配置

VisualStation 网关按 `CREATIVE_STUDIO_ROOT` 条件挂载。服务进程需安装本仓库依赖及 FastAPI、httpx。

服务端设置：`CREATIVE_MODEL_URL`、`CREATIVE_MODEL_KEY_FILE`（600 权限）、`CREATIVE_MODEL`、`CREATIVE_GSAP`、`CREATIVE_HYPERFRAMES`、`CREATIVE_FFMPEG`、`CREATIVE_FFPROBE`。可选 `CREATIVE_DATA_DIR`。

只支持一个网关 worker；异步任务锁当前属于单进程。项目和任务编号持久化，服务重启后展示恢复入口，恢复先查询已有编号/复用原幂等键。凭证不写进项目、事件或网页。

## 当前创作范围

当前新片只开放15秒原生有声音视频，支持16:9 / 9:16 / 1:1。时间轴的三个5秒节拍统一编译成一次模型请求，不独立生成镜头或拼接；后期仅准确叠加字幕并保留完整原片声音。视频与图片模型在导演输入区分别选择，详细目录列出已接入和未开放型号及原因。H3整片路径未验证，不能因节点连通就开放。

「检查制作服务」只读显示视频制作服务连通/处理状态和检查时间，不检查供应商授权或余额，不产生生成费用。商品参考与导演素材分开；方案、预算、账户权限和任务恢复均由服务端校验。成片保持待内容审阅，训练资格默认关闭。上手步骤见 `docs/creative_studio_quickstart.md`，持续目标见 `docs/advertising_agent_roadmap.md`。

暂停跟进不取消供应商已接收的整片；恢复查询原任务。没有自动付费重试、参数变化或模型替换。生成后修改源画面、声音或镜头顺序需要新方案及再次费用确认；旧版保留。

### 成片修改与历史版本

已完成成片可在时间轴修改字幕、调整镜头顺序。保存后复用全部已完成镜头，按钮显示“重新合成 · 0 积分”；不会重新提交视频生成。原成片会归档到“历史成片”，按账户权限下载，支持分段读取。新合成按独立 render attempt 路径保存。

已有画面的 prompt 不允许在时间轴直接改写，避免把旧素材误标为新生成内容；改变画面需在导演对话中规划新方案并明确确认预算。规划新方案前也归档已完成成片。版本保存各自字幕、镜头顺序与质检状态；不自动通过语义或人审。

本地实测：将 10 秒香水样片结尾字幕改为“把片刻，留给自己”，新成片合成完成；积分变化为 0，旧版本返回 HTTP 206，浏览器无脚本错误。创作状态与权限测试合计 12 项通过。

### 审阅交付

成片下方“审阅这一版”提供“确认本版可用”和“需要修改”。修改意见不能为空，可转入导演对话输入；不会自动触发规划或付费生成。审阅只属于当前版本，改字幕/镜头后需要重新确认。用户确认也不替代独立内容审查。审阅权限、版本失效与非训练自动准入纳入测试，创作测试共 15 项。

### 模型与预算（2026-09-29）

新建项目支持 Kling 2.5 / 3.0 / O3 与 MiniMax H3。能力以本账户 `who_am_i` 声明为依据；当前 Kling 选项均明确请求静音。每开始 5 秒，平台积分分别为 2 / 3 / 4 / 1，不是供应商灵感值或货币报价。服务端校验型号与时长、计算预算，确认后才提交；历史镜头继续复用，不再次扣费。

网关按实际扣费金额记账和退款；提交结果不确定时保留原记录，避免自动重发。新 Kling 适配器先落盘供应商编号再查询，进程重启可继续查同一任务。需要 VisualStation 对应模型预算与适配器挂载更新，单独更新网页不足以启用此功能。
